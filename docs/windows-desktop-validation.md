日期：2026 年 10 月 27 日。范围为 FinGuard 0.3.0 Windows x64 便携包。业务继续使用虚构数据；本轮没有真实银行交易和付费模型请求。

原生窗口查询得到 1,500 元执行时余额，并显示完成与证据。导出检查确认打开系统保存窗口；本次不把“打开保存窗口”表述为已校验导出文件内容。

最终 EXE 实测初始化约 17.44 秒，已有数据再次启动约 5.41 秒。该记录来自本机单次模拟自检，受磁盘、系统和缓存影响，不作为其他电脑的性能承诺。

本轮将业务、诊断和设置页分包加载。首屏入口与共享 JavaScript 合计约 452.26 KB，改动前约 478.81 KB；压缩后约 142.03 KB，改动前约 146.11 KB。这是构建体积，不是实际首屏耗时。

## 包与数据检查

便携目录包含独立桌面程序、项目引擎、模拟银行、前端构建和固定版本数据库程序。构建脚本只复制指定文件，生成输入及输出文件摘要，保留第三方许可。开发 `.env`、密钥、演示令牌、数据库和日志不进入包。

真实可执行文件检查使用独立的 `artifacts/` 数据目录。开发库和用户默认数据目录保持独立。包内程序退出后关闭自己的端口；不停止已有的 8000、8001 开发服务及其数据库。

## 验证限制

当前为未签名便携软件，依赖 WebView2 Runtime。没有安装向导、自动升级、跨电脑迁移或正式身份服务。本次在开发机实际运行，不能替代全新 Windows 10、Windows 11 虚拟机及不同权限、不同安全软件环境的兼容性测试。

桌面自检未覆盖任意故障组合。业务授权、并发和未知结果规则继续由[后端验证](backend-validation.md)及[前端验证](frontend-validation.md)支撑。新建桌面构建工作流的远端结果以对应提交为准。
