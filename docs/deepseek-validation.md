## 已执行验证

新增 13 项测试已通过，覆盖工具循环、推理字段透传、错误候选修正、重复调用、未注册工具、输出截断、401/402/429、请求预算、并发上限、缺少密钥和 HTTP 授权等待。

测试还使用相同测试入口及模拟 HTTP 响应，验证隔离业务回放。该检查证明测试流程和控制边界可以运行，不代表 DeepSeek 服务的实测表现。完整回归在 Windows 的 Python 3.14.0、3.12.10 上分别通过 202 项，耗时 320.12 秒、322.22 秒。其后针对密钥格式及会话隔离的 11 项无数据库检查复验通过。Ruff 检查和 0.3.0 源码包、wheel 构建通过。远端检查在同步后核实。

详细本地记录位于忽略的 `artifacts/pytest-deepseek-py314.xml` 和 `artifacts/pytest-deepseek-py312.xml`。本轮没有使用真实密钥或真实模型生成结果计算性能指标。
