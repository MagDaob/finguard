# FinGuard 0.3.0 发布说明

状态：未发布的预览候选。整理日期：2026 年 10 月 27 日。预定标签为 `v0.3.0`，本说明不表示该标签或 GitHub Release 已创建。

## 本版内容

- 提供任务、计划、逐项确认、执行状态、业务证据和导出工作台。
- 支持模拟转账、账单、产品申赎、临时锁卡、订阅合同及受限委托。
- 提供 Windows x64 便携软件，分别运行桌面外壳、项目后端、模拟银行和数据库。
- 增加用户数据隔离、受保护配置、本机会话、单实例、服务身份校验、重启恢复和退出清理。
- 支持中文程序与数据目录；业务、设置及诊断页面按需加载。

## 使用与兼容性

解压完整软件包，双击 `FinGuard/FinGuard.exe`。数据位于 `%LOCALAPPDATA%\FinGuard`。默认使用虚构数据和模拟规划器，没有内置模型 API key。

目标为 Windows 10 1903 及之后版本、Windows 11 x64，需要 WebView2 Runtime。当前为未签名便携版，已经完成开发机原生窗口及云端 Windows 的 EXE 自检，尚未完成所有目标系统的兼容性验证。

升级时保留上一版本程序包和用户数据。首个桌面版本尚无自动升级、安装向导、跨电脑迁移或一键回滚工具。数据库迁移后，不保证旧程序可直接写入新数据。

## 验证与限制

已验证转账确认前不扣款、凭证、幂等、单实例、重启持久化、中文路径和退出清理。发布目录中的 `VERIFICATION.json` 记录本次实际压缩包的自检与摘要；历史检查不能代替该文件。

真实银行、正式身份登录、真实额外身份验证、桌面模型密钥管理、连接激活及第三方插件执行未包含在本版。模拟业务和模型真实调用的历史结果分别记录，不把它们解释为真实银行验收。

项目采用 Apache-2.0，许可文本和 NOTICE 随交付材料提供；第三方许可分别保留。本次准备仅整理交付材料，未执行公开发布。
