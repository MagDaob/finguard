## 验收结论与依据

| 行为 | 检查依据 |
|---|---|
| 未授权写入被阻断 | 缺少确认、过期、撤销、参数变化和委托限额测试 |
| 并发不重复记账 | 同操作 16 次并发、同任务并发、不同任务争用账户与委托 |
| 未知结果先核实 | 响应丢失、查询未知、结构异常及提交前后中断测试 |
| 实际进程恢复 | HTTP 服务保存提交意图，模拟银行已付款后丢失响应；停止服务进程，再启动新进程，恢复为成功且仅有一条扣款流水 |
| 已完成事实保留 | 部分完成重规划、版本冲突、不可变节点和旧授权失效 |
| 混合故障状态收敛 | 一笔结果未知、另一笔失败时继续核实；收敛后报告部分完成 |
| 停止不抹去付款 | 当前提交继续核实，后续未提交节点取消 |
| 证据不足不成功 | 删除流水后，业务结果保持待核实，不能生成成功结论 |
| 业务语义区分 | 退款统计、理财风险与窗口、到账条件、结算失败恢复、合同与代扣、临时锁卡补偿 |
| 优化隔离和回退 | 回放不改运行库，固定回放不能批准模型策略；模拟网关通过对照评估、显式审核和发布回退 |

五个回放场景包括有效确认、等待授权、响应丢失、提交前中断和赎回到账后转账。合法任务完成率为 3/3，正确处理率为 5/5。授权、参数、重复入账、账本平衡、主体、证据、委托预算和最低余额检查均通过。这些比率只描述该固定模拟套件。

## 验证边界

当前没有真实模型凭据，也未连接银行、支付机构或商户。模型协议、非法候选拦截和策略流程使用模拟 HTTP 网关验证，不能据此宣称真实模型质量提升。

未执行大规模压力测试、随机属性测试、生产身份联调和真实系统灾难恢复演练。真实银行是否支持幂等键、权威查询或取消栅栏，必须在适配接入阶段重新确认。
