# 参赛材料

本目录保存 FinGuard 0.3.0 参赛材料的可编辑内容。生成的 PDF、PPTX 和源码包位于被忽略的 `dist/submissions/`，与软件发行目录分开。

| 平台分类 | 内容来源 | 交付格式 |
|---|---|---|
| 技术文档 | [技术文档](technical-document.md) | PDF，含架构、核心算法和安全设计 |
| 答辩材料 | [逐页讲稿](defense-script.md)、[演示设计](presentation-design.md) | 12 页 PPTX 与 PDF，建议 8 分 50 秒 |
| 源码与部署 | [部署入口](deployment.md)、受版本管理文件 | ZIP，含 README、部署说明与测试 |
| 安全自评 | [安全报告](security-self-assessment.md) | PDF，含权限矩阵、控制映射与风险 |

材料依据当前模拟实现和已有验收。真实银行、正式身份、通用模型网络适配和第三方插件执行仍待开发。历史指标注明日期、配置和样本限制，不混合不同阶段的测试数量。

源码包从明确的 Git 提交生成，排除运行数据与本机秘密。交付清单记录提交编号、摘要、尺寸和编制日期。生成材料与同步仓库不表示已上传参赛平台。

技术与安全材料每类上限为 50 MB，答辩材料为 80 MB，源码包为 300 MB。交付前按更严格的十进制字节上限检查。
