# 设计决策与待定事项

更新日期：2026 年 10 月 27 日。依据为[原始框架](sources/project-framework.txt)，范围为 0.3.0 模拟业务后端与模型接入。

## 核心决策

| 选择 | 理由与代价 |
|---|---|
| 显式关联任务、计划、授权、操作和证据 | 对话与工作流检查点不能替代业务事实 |
| 模块化单体 | 便于跟踪事务和调试，先验证控制边界，再按负载拆分 |
| 独立应用与模拟银行服务 | 分开目录、环境、进程、数据库与账号，通过认证 HTTP 通信；继续检验提交间隙、锁和恢复语义 |
| 稳定操作编号与参数摘要 | 重复执行复用身份，参数冲突被拒绝；新业务尝试需新节点与授权 |
| 单次授权和受限委托分开 | 确认绑定参数，委托额外限制白名单、单笔、累计、频次及期限 |
| 行锁消费授权，银行锁内复检资金 | 防止并发透支和重复消费；连接与锁开销需在容量测试中继续衡量 |
| 未知结果先核实 | 超时、回调文本和查询未找到都不足以证明付款未生效 |
| 不引入工作流框架或消息队列 | 当前数据库状态与显式调度足够；扩展时保持业务状态独立 |
| 模型网关与确定性编译分开 | 候选不能扩张目标或权限；开放意图理解与真实模型质量另行评估 |
| 回放隔离、优化需审核 | 提示词改进不能修改业务授权、账本和控制规则 |

## 已采用的工具

具体安装版本以 [uv.lock](../uv.lock) 为准。

| 项目 | 当前选择 | 使用范围 |
|---|---|---|
| 运行时 | Python 3.12 至 3.14，默认 3.14 | 核心包、后端和管理入口 |
| 依赖管理 | uv 0.11.14 | 隔离环境与可复现安装 |
| 数据校验 | Pydantic 2.14.1 | 严格金额、额外字段拒绝和结构化输入 |
| HTTP 服务 | FastAPI 0.162.0、Uvicorn 0.54.0 | 认证接口、文档和后台恢复循环 |
| 数据库 | PostgreSQL 18.6、Psycopg 3.3.6 | 本机并发、授权、账本与恢复验证 |
| HTTP 客户端 | HTTPX 0.28.1 | 可替换规划网关、超时及模拟 HTTP 测试 |
| 测试与格式 | pytest 9.1.1、Ruff 0.17.2 | 规则、并发、故障、接口和代码检查 |
| 打包与部署 | Hatchling、Dockerfile、Compose | 安装包与容器入口 |

普通业务访问令牌由可信本机命令签发，适合开发集成。正式身份平台、外部 OAuth、账户开户和跨机构授权不在当前范围。

## 前端实现决策

首版采用 React、TypeScript 和 Vite，配合 React Router、TanStack Query、Zod 与 lossless-json。原生表单和 `dialog` 满足当前键盘及焦点需求，未增加组件框架。依赖版本以 [package-lock.json](../frontend/package-lock.json) 为准。

浏览器会话只保存在内存，身份切换时清除缓存；金融写入不自动重试、不乐观宣布成功。金额在 JSON 解析阶段保留整数精度。现有动态接口采用人工核对的运行时契约，暂未生成 OpenAPI 类型。

构建产物可由后端在本机同源提供，容器使用独立 Nginx 代理。模拟银行保持独立目录、运行环境和服务边界。使用与实际验证见[前端入口](../frontend/README.md)及[验收记录](frontend-validation.md)。

## Windows 桌面决策

桌面外壳采用 pywebview 6.2.1 和系统 WebView2。使用独立 Python 3.12 构建环境、PyInstaller 6.22.3 和锁文件，分别冻结外壳、后端和模拟银行。首版交付完整便携目录及压缩包，避免单文件每次解压数据库程序带来的启动成本。具体版本以 [Windows 锁文件](../packaging/windows/uv.lock)为准。

数据库随程序提供二进制，数据保存在当前用户目录，项目与模拟银行仍使用不同数据库账号。Windows DPAPI 保护本机凭据，Job Object 回收自有后代进程。该桌面会话是本机模拟入口，不替代正式身份系统。边界与验证见[桌面说明](windows-desktop.md)。

## DeepSeek 接入决策

0.3.0 按用户要求增加 DeepSeek 官方接口，直接使用现有 HTTPX，不新增 SDK 依赖。默认模型按当日官方文档配置为 `deepseek-flash`，支持可选思考模式和用量诊断。按需工具循环、全量对照及请求预算见 [设计说明](deepseek-design.md)。真实性能和任务效果以 [专项验收](deepseek-validation.md)为准。
