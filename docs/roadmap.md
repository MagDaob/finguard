# 开发路线

截至 2026 年 10 月 27 日，0.3.0 已实现模拟业务后端、前端工作台，并接入 DeepSeek 官方协议及有界工具循环。DeepSeek 此前已完成小规模真实 API 与 Agent 对照验收，见 [专项记录](deepseek-validation.md)。本轮前端联调使用确定性规划器和虚构数据，见[前端验收](frontend-validation.md)。真实银行效果不包含在模拟验收结论中。

## 阶段与验收

| 阶段 | 当前产物 | 状态 |
|---|---|---|
| P0：项目准备 | 原文归档、架构、约定和场景 | 已完成 |
| P1：领域与工具契约 | 核心对象、状态、工具模式、模拟账户与账本 | 已完成模拟实现 |
| P2：可靠执行 | PostgreSQL、稳定操作编号、幂等、未知核实和恢复 | 已完成模拟实现 |
| P3：授权与策略控制 | 令牌权限、单次授权、受限委托、预算、频次及并发检查 | 已完成模拟实现 |
| P4：任务编排 | 计划版本、依赖、条件、停止、部分完成、证据与 HTTP 接口 | 后端与首版工作台已实现 |
| P5：动态规划与专业能力 | 有限意图解析、澄清、计划编译、局部重规划、模型网关、各业务专业工具 | 真实短计划闭环已验证；开放理解待评估 |

| P7：离线优化 | 失败草案、隔离对照评估、审核发布和版本回退 | 流程已完成；长期策略质量待评估 |

## 已跑通的主线

项目与模拟银行已完成目录和服务拆分。双方分开运行环境、配置、进程及数据库账号，通过 HTTP 接口通信，见[服务隔离](service-isolation.md)。

初始模拟余额 1,500 元，给小王转 300 元，至少保留 1,000 元。无授权时等待；有效确认后仅入账一次，最终余额 1,200 元，生成业务记录、流水和余额证据。

同一执行控制覆盖账单、理财、卡片、订阅及条件组合任务。赎回需实际到账，订阅合同取消与代扣授权分开，临时锁卡恢复采用新任务和新授权。

验证说明见[后端验收记录](backend-validation.md)和[测试入口](../tests/README.md)。

## 后续工作

[银行、模型与插件接口准备](integration-platform-plan.md)已实现，实际入口见[扩展接口说明](extension-interfaces.md)。银行领域仍以个人银行卡为主要设计对象。

本轮提供银行连接与能力声明、模型地址与密钥引用、统一消息与响应，以及插件清单、调用和元数据生命周期契约。模式目录和本地校验接口可运行；现有独立模拟银行与 DeepSeek 继续保留。

后续按用户指令选择真实适配、连接持久化或插件运行平台。这些服务能力尚未实现；配置通过校验不会自动激活连接或授予权限。

参考项目对照发现的后端问题已补充修复：完整分句匹配、常见金额表达、自然月与分类账单、受限任务追问、额外验证门槛及脱敏，见[专项说明](understanding-and-privacy.md)。任意多轮对话和实际身份验证服务仍需独立开发。

后续开发继续按可验证的改动提交并同步仓库。原始框架保留完整目标，当前能力以代码、测试和运行说明为准。

## 前端设计进展

2026 年 10 月 27 日，已按[前端工作台设计方案](frontend-design.md)实现 F1 至 F3 的现有接口范围，包含任务、确认、凭证、业务页面、诊断和配置校验。完成 27 项前端测试、317 项后端回归及隔离双服务浏览器联调，详见[验收记录](frontend-validation.md)。

F4 继续等待正式身份、额外验证、连接管理、全局待办及跨页面关闭后的创建请求恢复接口。复杂目标补全与多步骤重规划目前使用完整 JSON 编辑器；策略评估、发布与回退尚未进行本轮浏览器专项验收。

2026 年 10 月 29 日，新增[前端改版设计](frontend-redesign.md)。结构参考 LibreChat，采用对话式任务与按需成果面板，视觉采用 Geometric Bold。本轮仅完成设计；现有前端与桌面包尚未应用改版。

## Windows 桌面进展

已增加 Windows x64 便携桌面入口。软件独立管理本机数据库、项目后端和模拟银行，采用受保护配置、随机端口、本机会话和有界退出；不继承开发机密钥。页面增加按需加载。构建与当前验收范围见[桌面说明](windows-desktop.md)和[验收记录](windows-desktop-validation.md)。正式身份、模型密钥管理、安装向导和自动升级继续独立规划。

## 发布准备进展

项目所有者确认采用 Apache-2.0。已增加变更记录、版本说明、文档索引及发布附件模板；准备脚本核对版本、许可、完整文件、摘要和构建输入，在独立中文目录中执行 EXE 自检，再生成版本化交付目录。旧构建与测试目录保留在本机归档中，当前用户数据继续隔离。执行方法见[发布流程](releasing.md)；尚未创建标签或公开 Release。
