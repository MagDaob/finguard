# 开发路线

截至 2026 年 10 月 27 日，0.3.0 已实现模拟业务后端，并接入 DeepSeek 官方协议及有界工具循环。后端开发按用户本次要求先完成，前端工作台继续作为独立阶段。DeepSeek 已完成小规模真实 API 与 Agent 对照验收，见 [专项记录](deepseek-validation.md)。真实银行效果不包含在模拟验收结论中。

## 阶段与验收

| 阶段 | 当前产物 | 状态 |
|---|---|---|
| P0：项目准备 | 原文归档、架构、约定和场景 | 已完成 |
| P1：领域与工具契约 | 核心对象、状态、工具模式、模拟账户与账本 | 已完成模拟实现 |
| P2：可靠执行 | PostgreSQL、稳定操作编号、幂等、未知核实和恢复 | 已完成模拟实现 |
| P3：授权与策略控制 | 令牌权限、单次授权、受限委托、预算、频次及并发检查 | 已完成模拟实现 |
| P4：任务编排 | 计划版本、依赖、条件、停止、部分完成、证据与 HTTP 接口 | 后端已完成；前端待开发 |
| P5：动态规划与专业能力 | 有限意图解析、澄清、计划编译、局部重规划、模型网关、各业务专业工具 | 真实短计划闭环已验证；开放理解待评估 |
| P6：调试与评估 | 轨迹、导出、故障注入、固定目标与模型回放、分层归因 | 后端已完成；调试界面待开发 |
| P7：离线优化 | 失败草案、隔离对照评估、审核发布和版本回退 | 流程已完成；长期策略质量待评估 |

## 已跑通的主线

项目与模拟银行已完成目录和服务拆分。双方分开运行环境、配置、进程及数据库账号，通过 HTTP 接口通信，见[服务隔离](service-isolation.md)。

初始模拟余额 1,500 元，给小王转 300 元，至少保留 1,000 元。无授权时等待；有效确认后仅入账一次，最终余额 1,200 元，生成业务记录、流水和余额证据。

同一执行控制覆盖账单、理财、卡片、订阅及条件组合任务。赎回需实际到账，订阅合同取消与代扣授权分开，临时锁卡恢复采用新任务和新授权。

验证说明见[后端验收记录](backend-validation.md)和[测试入口](../tests/README.md)。

## 后续工作

下一阶段优先处理[银行、模型与插件接入规划](integration-platform-plan.md)。该文档目前为待实施草案；用户已明确以个人银行卡为主，企业接口仅作技术参照。

1. 定义连接、能力、版本与插件契约，建立国内模型的通用接入层。
2. 按银行正式产品能力接入个人账户只读查询，再独立验证写入、授权与核实。
3. 实现受控工具注册表和隔离插件运行，支持只读分析、报表及任务模板。
4. 建立前端任务工作台及接入配置入口，扩展代表性意图与复杂规划评估集。
5. 面向正式部署补充身份平台、集中监控、限流、备份恢复演练与性能容量验证。

后续开发继续按可验证的改动提交并同步仓库。原始框架保留完整目标，当前能力以代码、测试和运行说明为准。
