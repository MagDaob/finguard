## 实现取舍

采用模块化单体，核心业务集中在 `src/finguard/backend/`。业务状态由 PostgreSQL 保存。FastAPI 提供接口，恢复循环可内置或独立运行；现阶段无需额外消息队列或工作流框架。

模型网关只接收已经确认的结构化业务目标，返回候选编排。控制程序要求目标、参数和必要条件完整保留。当前不允许模型从开放文本直接生成可执行授权。

模拟银行与应用采用独立事务。先保存提交意图，再提交银行操作；响应丢失或进程重启后查询原操作。模拟查询栅栏可以明确阻断迟到请求，这项保证不能直接移植到真实银行。
