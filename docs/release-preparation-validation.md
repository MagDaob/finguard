## 保留限制

当前为模拟业务、未签名便携版，依赖系统 WebView2。完整目标系统的原生 GUI 兼容性、正式身份、自动升级和跨电脑迁移未在本次准备中实现。依赖清单明确区分构建环境与前端生产依赖，不声称是完整运行时软件物料清单。

Apache-2.0 项目许可不会覆盖第三方组件的条款。准备产物和 Actions 附件不等于公开 Release；正式公开交付的具体操作遵循后续用户指令。
