# FinGuard 前端工作台

本目录实现[前端设计](../docs/frontend-design.md)中的任务工作台和业务页面。页面访问 FinGuard API；模拟银行、模型和数据库由后端连接。全部业务数据来自接口。

## 启动

需要 Node.js 24.12.0 和 npm。依赖由 `package-lock.json` 固定。先按[项目入口](../README.md)启动后端，再在本目录运行：

```powershell
npm ci
npm run dev
```

打开 `http://127.0.0.1:5173/tasks`。开发服务器将 `/v1`、`/health` 转发到本机 8000 端口。需要更换目标时，在启动前设置服务端变量 `FINGUARD_API_TARGET`。该变量不写入浏览器构建。

访问令牌从本机忽略文件 `artifacts/demo-tokens.local.json` 获取，在页面输入。页面只在内存中保留令牌；刷新后重新输入，任务通过原编号恢复查看。不要将密钥放入前端环境变量、地址栏或代码。

## 构建与部署

```powershell
npm run build
```

输出位于忽略的 `frontend/dist/`。从项目根目录启动或重启后端后，可直接访问 `http://127.0.0.1:8000/tasks`。后端只挂载构建目录和约定的页面路由；未构建时继续提供纯 API。可用 `FINGUARD_FRONTEND_DIRECTORY` 指定其他构建目录。

另有独立的 Nginx 容器，由根目录 [compose.yml](../compose.yml) 构建，在本机 5173 端口提供页面并代理后端。容器不包含模型或银行凭据。容器部署仍需按正式环境配置身份、TLS 和运维措施。

## 页面与边界

| 页面 | 当前能力 |
|---|---|
| 任务工作台 | 自然语言、转账表单、完整步骤、计划、预览确认、轮询、停止、重规划、证据和导出 |
| 账户与账单 | 当前余额、分页流水、自然月与分类账单任务 |
| 授权管理 | 受限委托创建、预算、期限和撤销；单次授权位于对应任务 |
| 产品与持仓 | 风险和窗口、持仓、申购与赎回任务 |
| 卡片与订阅 | 临时锁定与解除、取消订阅合同 |
| 连接与设置 | 会话权限、退出与撤销、扩展目录、配置格式校验 |
| 开发诊断 | 任务轨迹、计划差异、候选详情、回放、评估、发布和回退入口 |

普通用户只查看自己的任务诊断；评估入口需要相应权限和服务端功能开关。模型评估可能消耗配置服务的额度，界面要求单独确认。本次界面验收没有调用付费模型。

确认前重新查询任务、参数摘要和预览。冲突后必须复核新内容；写请求关闭自动重试。创建任务遇到响应丢失时，同一页面保留原请求编号和完整内容。关闭页面后的创建请求恢复尚无专用后端接口。

金额输入按整数算法转换为分；超出输入安全范围时拒绝。响应通过无损 JSON 解析保留大整数。界面展示的预计余额仅供确认，执行结果以服务端业务证据为准。

复杂多步骤补全和重规划目前使用完整 JSON 编辑器，单笔转账提供表单。正式登录、额外身份验证、连接持久化和插件执行尚未实现；高金额验证不可用时保持阻断。配置格式校验不会启用连接或授予权限。

## 目录与验证

| 文件 | 职责 |
|---|---|
| `src/api.ts`、`src/money.ts` | 接口校验、错误边界、整数金额与无损 JSON |
| `src/session.tsx`、`src/hooks.ts` | 内存会话、主体缓存、请求与轮询 |
| `src/tasks.tsx`、`src/state.ts` | 任务交互、确认边界与状态呈现 |
| `src/business.tsx` | 账户、产品、服务和受限委托 |
| `src/lab.tsx`、`src/settings.tsx` | 诊断、评估与配置校验 |
| `src/ui.tsx`、`src/styles.css` | 基础交互、响应式布局和样式 |
| `src/test/` | 金额、状态、会话和关键交互测试 |

```powershell
npm run format:check
npm test
npm run build
```

实际检查及限制见[前端验收记录](../docs/frontend-validation.md)。模拟双服务验收可从根目录运行 `uv run --locked python scripts/frontend-qa.py`，另在本目录设置 `FINGUARD_API_TARGET=http://127.0.0.1:8002` 后启动开发服务器。QA 服务使用临时双数据库命名空间、虚构数据和确定性规划器；按 Ctrl+C 退出后清理本次命名空间。令牌和日志只保存在忽略的 `artifacts/frontend-qa/`。

由后台终端启动时，可在项目根目录执行 `New-Item artifacts/frontend-qa/stop.local -ItemType File -Force` 请求正常关闭。脚本停止自有子进程、清理本次命名空间并移除临时令牌。强制结束整个进程树可能跳过退出清理。
